# Vibe Games

A collection of small browser games, vibe-coded with Claude Code.

- **[Bob the Blob](bob-the-blob/)** — a 3D eat-and-grow game about a very hungry blob. (Three.js + Vite)
- **[Pinguinos](pinguinos/)** — a 3D penguin adventure across Boulders Beach and beyond. (Three.js + Rapier + Vite)
- **[Claude's Adventure](claudes-adventure/)** — a pixel art platformer in a single HTML file. Just open
  `claudes-adventure/index.html` in a browser.

See each game's README for setup and controls.
