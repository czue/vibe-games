# Pinguinos

A 3D browser game where a penguin waddles around Boulders Beach, finds a shell key, and unlocks a boulder to complete the level.

Built with Three.js, Rapier physics, Vite, and TypeScript.

## Quick Start

```bash
cd pinguinos
npm install
npx vite
```

Then open the URL shown in the terminal (usually http://localhost:5173).

## Controls

- **WASD / Arrow Keys** — Move
- **Space** — Jump

## How to Play

1. Explore Boulders Beach
2. Find the glowing golden shell key
3. Bring it to the large boulder with the golden keyhole
4. The boulder slides aside — level complete!
